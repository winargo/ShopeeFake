# ShopeeFake 📱

ShopeeFake is an Android application project developed in **Java** as part of an academic task for **Universitas Mikroskil**.  
This project demonstrates practical implementation of mobile development concepts, focusing on user interface design, data handling, and e-commerce simulation features.

---

## ✨ Project Overview
ShopeeFake is designed to mimic the basic functionality of an online shopping platform.  
It provides a learning environment for students to:
- Understand Android app architecture.
- Apply Java programming in mobile development.
- Explore UI/UX design principles.
- Practice data management and modular coding.

---

## 🛠️ Tech Stack
- **Language:** Java  
- **Framework:** Android SDK  
- **IDE:** Android Studio  
- **Database:** SQLite / Local storage (depending on implementation)  

---

## 📂 Project Structure
- `app/src/main/java/` → Core Java classes and logic  
- `app/src/main/res/layout/` → XML layouts for UI components  
- `app/src/main/res/values/` → Styles, colors, and strings  
- `AndroidManifest.xml` → App configuration  

---

## 🎯 Learning Objectives
- Strengthen understanding of Android lifecycle and components.  
- Implement reusable and maintainable Java code.  
- Simulate real-world e-commerce workflows (product listing, cart, checkout).  
- Gain experience in collaborative academic projects.
